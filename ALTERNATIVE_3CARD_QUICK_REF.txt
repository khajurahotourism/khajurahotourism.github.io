AUTOMATIC ROTATION:
  1. Page loads → Shows Group 0 (cards 19-21)
  2. Waits 6 seconds
  3. Smoothly transitions to Group 1 (cards 22-24)
  4. Waits 6 seconds
  5. Loops back to Group 0
  6. Continues indefinitely

MANUAL NAVIGATION (Clicking Dots):
  1. User sees: ● ○ (Group 0 active)
  2. User clicks: ○ (second dot)
  3. Instantly shows: Group 1
  4. Dot changes to: ○ ● (Group 1 active)
  5. Auto-rotation timer resets
  6. After 6 seconds, rotates back to Group 0

VISUAL FEEDBACK:
  ● Active dot (larger, primary color)
  ○ Inactive dot (smaller, muted color)
  Hover inactive dot → brightens on hover

  TECHNICAL SPECIFICATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STATE MANAGEMENT:
  altCarouselGroup = current group index (0 or 1)
  cardsPerGroup = 3 (constant)
  totalAltGroups = 2 (calculated from total cards)

AUTO-ROTATION:
  Interval: 6000ms (6 seconds)
  Effect: setAltCarouselGroup((prev) => (prev + 1) % totalAltGroups)
  Loops: Yes (uses modulo operator)

CARD SLICE LOGIC:
  startIndex = 18 + (group * 3)
  endIndex = startIndex + 3
  
  Group 0: slice(18, 21) → reviews 19, 20, 21
  Group 1: slice(21, 24) → reviews 22, 23, 24

DOT CLICK HANDLER:
  onClick={() => setAltCarouselGroup(dotIndex)}
  Instantly changes group
  Resets auto-rotation timer
